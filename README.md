# Netflix Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix dataset to uncover insights about movies and TV shows available on Netflix.

## Objectives
- Analyze Netflix content distribution.
- Compare Movies and TV Shows.
- Identify trends in content releases over the years.
- Explore content ratings and genres.
- Visualize key patterns using charts and graphs.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset Features
- Title
- Type (Movie/TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre

## Analysis Performed
- Data Cleaning
- Handling Missing Values
- Content Type Analysis
- Year-wise Content Growth
- Country-wise Content Distribution
- Rating Analysis
- Genre Analysis
- Data Visualization

## Key Insights
- Movies make up the majority of Netflix content.
- Significant growth in content additions occurred after 2015.
- Certain countries contribute the highest number of titles.
- TV Shows and Movies differ in rating distribution.

## Project Outcome
The analysis provides valuable insights into Netflix's content library and trends, helping understand viewer preferences and content strategies.
